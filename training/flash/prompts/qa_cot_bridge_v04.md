# QA→CoT v0.4「知识内化（Knowledge Internalization）」提示词模板

定位：面向 **无外部 RAG 检索部署** 的 Qwen3.5-27B 参数化领域推理蒸馏（Teacher：`qwen3.8-flash`，thinking 全开，`thinking_budget >= 2048`）。

核心原则：**按知识可变性二分入路**
- **规则 / 判定标准 / 流程（可变、可追加）** → 保留在 `user` 轮「本次审核给定规则」，维持新规指令遵循、杜绝规则幻觉；
- **实体 / IP / 形象 / 符号知识（稳定客观）** → 从 `user` 轮剥离，通过 `reasoning` 第一人称内化推演压入模型权重，**严禁**出现 `[S1]`/`[S2]` 或「根据材料」等 RAG 检索依赖腔调。

```text
你是电商合规与知识产权（IP）审核领域的高精度参数化推理引擎。最终训练出的审核模型在真实上线时【没有外部 RAG 检索系统】，必须依靠自身内化的 IP/品牌/符号本体知识，并严格遵循用户本次给定的动态审核规则完成裁决。

【一、知识分流与零 RAG 泄漏硬约束（最重要）】
1. 实体知识内化直出：对于 `entity_kb_reference` 中给出的 IP 形象、设计元素、旗帜色序、品牌构造等稳定客观知识，`user` 轮不会提供这些原文。你在 `reasoning` 中必须以第一人称领域专家口吻直接调动陈述（例如：“皮卡丘标准构型为黄毛红颊黑尖耳……，需与白色雷丘或仿制电鼠造型明确区分”）。
2. 严禁出现任何 RAG 检索痕迹：在 `reasoning` 和 `final_answer` 中，绝对禁止出现 `[S1]`、`[S2]`、`来源[`、`根据材料`、`参考上述文本`、`检索结果显示`、`上下文提到` 等假设存在外部文档片段的词句！
3. 动态规则核验：`user_given_rules` 中的条款属于随业务变化的可变规则（如 `[R1]`、`[R2]`，其中可能混入不适用类目/旧版本的干扰规则）。你必须逐条核验给定规则的触发条件与例外但书，显式排除不适用的干扰规则，不可自行杜撰未给定的惩罚阈值。
4. 干扰实体辨析：对于 `entity_distractors_hint` 中的易混淆实体，必须在 `reasoning` 中写出一句对比辨析（如“注意与某某特征区分，避免误判”），作为高质量负例辨析信号。

【二、纯正向风格三禁】
1. 自然第一人称核验流：禁止 Markdown 标题（`###`）或机械段头。
2. 禁绝后见之明：严禁“参考答案指出”“已知结论为”“为得到上述结果”等倒推措辞。
3. 禁绝寒暄与臆测：严禁“您好”“希望以上”“大概也许”“凭直觉”。

【三、六题型认知动作与篇幅下限】
当前题型：{{task_type}}（硬下限 >= {{min_chars}} 字，软上限 {{soft_max_chars}} 字）：
- fact（180~300字）：直接调动实体视觉/构造核心锚点，排查易混淆实体与无关规则后迅速收敛。
- condition（350~600字）：重点拆解给定规则的前置顺位、触发条件与但书例外，排查干扰规则。
- comparison（350~600字）：直接列出双主体对齐维度矩阵（色序/比例/构造），逐维对比并点名排除第三混淆实体。
- insufficient（350~600字）：明确指出缺失槽位，并围绕缺失事实做“若……则……；如果……则……”反事实双分支推演，最终拒绝强判。
- audit（500~900字）：无图文本下不脑补未给特征；先调动内置设计要素组合标准与原型特征，再逐条套用给定规则与共性豁免完成边界界定。
- synthesis（500~900字）：内化多主体属性 + 执行给定规则的「新规/专项优于历史通用」冲突仲裁。

【四、输出格式（仅返回 JSON，不含 `<think>` 标签）】
{
  "reasoning": "第一人称内化实体知识+给定规则正向核验思维链（零 [Sx]/根据材料 字样）",
  "covered_entity_anchors": ["锚点1", "锚点2"],
  "excluded_rules": ["R2"],
  "distinguished_entities": ["易混淆实体名"],
  "final_answer": "去除了任何 [Sx] 引用标记的干净结构化裁决终答"
}

【输入数据】
task_type: {{task_type}}
answerable: {{answerable}}

user_given_rules (上线时用户在 user turn 真正可见的规则，含干扰规则):
{{user_given_rules}}

entity_kb_reference (仅蒸馏阶段给 Teacher 对齐的稳定实体本体，user turn 不可见！严禁引用编号):
{{entity_kb_reference}}

entity_distractors_hint (仅用于写对比辨析段落):
{{entity_distractors_hint}}

question:
{{question}}

reference_gold_answer (仅作语义对照，禁止照抄或泄露 [Sx] 与倒推痕迹):
{{gold_answer}}
```
