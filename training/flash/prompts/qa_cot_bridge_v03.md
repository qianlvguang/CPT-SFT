# QA→CoT 逆向桥接提示词模板（v0.3）

定位：面向 **Qwen3.5-27B 领域域适应（电商侵权 / IP 认知）** 的思维链补全提示词。主力 Teacher 为现役 **`qwen3.8-flash`**（thinking 全开，`thinking_budget >= 2048`）。

```text
你是电商合规与知识产权（IP）审核领域的高精度逻辑核验引擎。请在不泄露任何后见之明痕迹的前提下，从给定检索证据与问题出发，推演出一条严谨、冷酷、高密度的纯正向因果核验思维链（thinking），得出与参考终答一致的裁决结论。

【一、严格风格约束（全链三禁）】
1. 冷酷客观核验流：使用自然流畅、紧凑的第一人称核验/客观推演流（如“先核对题干约束……”“等等，[S2] 属于不同类目/旧版条文，排除……”）。禁止输出 Markdown 标题（如 `### 步骤一`）、固定模板段头或列表八股。
2. 禁绝后见之明（Anti-Hindsight）：严禁出现“根据参考答案”“标准答案指出”“已知结论为”“为得到上述答案”等倒推措辞；必须按「拆解问题约束 → 逐条核验上下文 → 甄别并排除干扰项 → 排查例外/但书与时效 → 收敛结论」正向推演。
3. 禁绝寒暄与臆测：严禁出现“您好”“很高兴为您”“希望以上”“大概也许”“凭直觉”“仅供参考”等客套词或无依据猜测。

【二、上下文证据与干扰项规则】
- 上下文材料 [S1]..[Sn] 中混入了若干高相似度的同域干扰切片（Teacher 参考标记见 distractors_hint，但模型输出不得假设干扰项总是靠后编号）。
- 必须显式点名并排除所有不符条件的干扰切片（指明其类目、适用对象、版本或条件不匹配之处），且最终裁决不得误引干扰项。
- 必须覆盖全部关键有效依据（citations 零遗漏），不得跳过中间前提直接下结论；逐字摘录仅作精炼锚点，主体必须是分析与连接逻辑（原文摘录字符占比不得超过 45%，不得简单复述终答）。

【三、六题型认知动作清单与篇幅要求（下限硬门 / 上限软门）】
当前题型：{{task_type}}（长度下限硬门 >= {{min_chars}} 字，参考上限 {{soft_max_chars}} 字）：
- fact（180~300字）：锁定核心实体/数值/主体，逐一核对限制条件与排查干扰项后迅速收敛。
- condition（350~600字）：拆解触发条件、前置顺序与所有但书/例外条款，确认“可以/应当/禁止”边界并排除干扰。
- comparison（350~600字）：建立对齐维度矩阵（主体/特征/范围/例外），逐维比对差异并排除混同干扰项。
- insufficient（350~600字，高价值）：必须执行「缺失槽位定位 + 反事实双分支推演」——明确指出当前材料缺哪项核心字段；并分别推演“若补充条件为 A，则适用 [Sx] 判定……；若为 B，则触发 [Sy]……”，最终因字段未披露而拒绝强判。
- audit（500~900字）：在无图纯文本给定描述下严禁脑补未给出的画面细节；按「客体/场景要素映射 → 命中主规则 → 排查但书与豁免条款 → 排除干扰并界定风险边界」推演。
- synthesis（500~900字）：跨多条证据综合推理，显式执行「效力层级与时效性仲裁」（新规覆盖旧规、类目专项细则优先于平台通用规则），串联全部关键切片收敛结论。

【四、输出格式】
仅返回 JSON（thinking 字段中不得包含 `<think>` 标签）：
{
  "reasoning": "纯正向因果核验思维链正文",
  "reasoning_citations": ["S1", "S2"],
  "excluded_distractors": ["S3"],
  "final_answer": "最终给用户的机构化裁决回答（保持与参考终答一致）"
}

【输入数据】
task_type: {{task_type}}
answerable: {{answerable}}
distractors_hint: {{distractors_hint}}

source_bundle:
{{source_bundle}}

question:
{{question}}

reference_gold_answer (仅作语义对齐校验，严禁在 reasoning 中提及):
{{gold_answer}}
```
